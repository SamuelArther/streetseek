Streetseek

Describe a place, say roughly where it is, and Streetseek scans Google Street View in that area and gives you the top 5 matching spots. Each one comes with a photo, a blurred / not blurred check and a link that opens Street View at that exact spot and angle.

Download View on GitHub

How it works

  1. Area

    The place name is turned into map coordinates with OpenStreetMap. The search is a circle around it.

  2. Coverage

    Google's Street View coverage lists every panorama inside the circle.

  3. Map features

    If you name a kind of place (church, gas station, water tower…), OpenStreetMap finds them and the camera is aimed straight at each one.

  4. Street scan

    The rest of the budget goes to panoramas spread evenly over the area, each looked at in 6 directions.

  5. Ranking

    CLIP (ViT-L/14) scores how well each view matches your description, then rescans densely around the 8 best spots.

  6. Blur check

    The top matches, and the views beside them, are checked for Google's privacy blur on houses. Ask for a blurred house and only blurred spots come back, aimed right at the blur.

Install

Needs Python 3.10+ on Windows, macOS or Linux. An NVIDIA GPU makes it fast; CPU works but is slow. The first search downloads the CLIP model (~1.7 GB).

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt

Use it

Web UI: on Windows double-click streetseek.bat, or run this and your browser opens when it's ready:

python -m streetseek serve --open

Command line:

python -m streetseek "a red brick church with a tall pointed steeple" --area "German Village, Columbus, Ohio"
OptionDefaultWhat it does
--arearequiredTown, neighborhood, street, intersection or ZIP.
--radius500Circle radius in meters (50–2000).
--max-panos120How many Street View spots to check (5–300). More = slower but fewer misses.
--outresultsWhere reports are saved (an HTML page, the photos and a JSON file).

Tips

  • Describe what's visible from the street: colors, materials, roof shape, porches, signs, trees, fences.
  • Keep the area tight. A neighborhood works much better than a whole city.
  • CLIP gets the overall look but is fuzzy on details like which thing is red, so the right place is usually in the top 5 rather than always #1.
  • Imagery comes through the streetlevel library (no API key). It isn't officially supported by Google and can be rate limited, so keep searches reasonably small.
